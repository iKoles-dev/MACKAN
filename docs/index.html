MACKAN

Native macOS CKAN mod management for Kerbal Space Program.

A public preview of a SwiftUI/AppKit desktop app backed by CKAN Core, built for Mac players who want the familiar CKAN workflows without opening Terminal.

Install the Preview

The current preview is intended for Mac testers who are comfortable opening an ad-hoc signed app.

  1. Download Get MACKAN-0.1.0-preview.1-macOS.app.zip and the matching checksum from the preview release.
  2. Verify Check the downloaded zip with the release .sha256 file.
  3. Unzip Extract the archive and move or open MACKAN.app.
  4. Open If Gatekeeper blocks a normal double-click, use Finder right-click, Open, or approve MACKAN in System Settings → Privacy & Security.
  5. Report Send macOS version, KSP install source or path shape, and a short reproduction in GitHub Issues.
